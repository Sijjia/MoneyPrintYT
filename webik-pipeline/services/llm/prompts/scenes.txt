# ПРАВИЛА РАЗБИВКИ

## Длина сцены
- Минимум 3 секунды, максимум 8 секунд
- Средняя длина: 4-5 секунд
- Если фраза драматическая — может быть короче (2-3 сек)
- Если описательная — длиннее (6-8 сек)

## Темп монтажа
- Динамичные части (интро, шоковые моменты): сцены по 3-4 сек
- Спокойные описательные: 5-7 сек
- Драматические паузы из сценария: отдельная сцена с пустотой/затемнением

## Типы визуала (visual.type)
- `stock_photo` — статичная фотография из стоков (Pexels/Unsplash)
- `stock_video` — короткий стоковый видеоклип
- `ai_image` — генерируется через Flux/Midjourney
- `ai_video` — генерируется через Kling/Veo (используй ТОЛЬКО для критичных уникальных сцен — взрывы вакуума, нанороботы и т.д.)
- `archive` — архивные исторические фото (Wikimedia)
- `youtube_clip` — вырезка из публичного YouTube-ролика (хроника, интервью, документалка). Используй ТОЛЬКО когда первичный источник говорит сам за себя (политик противоречит себе, эксперт-инсайдер, архивная новостная съёмка). НЕ для атмосферных кадров — для них есть stock_video. Обязательно: `source_url`, `clip_start`, `clip_end` (sec), `caption` (атрибуция автора). Pipeline скачивает через yt-dlp + обрезает ffmpeg.
- `diagram` — схема/инфографика для генерации в Remotion (опционально)

ПРАВИЛО: 70% сцен — `stock_photo` (с 3D-камерой автоматически), 15% — `stock_video`, 10% — `ai_image`, 5% — `ai_video`. AI-видео дорогое и работает только на критичных моментах.

## Поисковые запросы (visual.search_query)
- 2-4 английских слова (стоки лучше ищут на английском)
- Конкретно. НЕ "капибара", а "capybara hot spring japan"
- НЕ "город", а "seoul night skyline"
- Используй конкретные имена/места если есть (для archive)

## AI-промты (visual.ai_prompt)
- Английский, детальный, с тегами пресета
- Формат: `{сцена}, {tags пресета}, {style модификаторы}, --ar 16:9`
- Пример MYSTIC: `Korean shaman performing ritual in foggy mountain temple, dark folklore aesthetic, candle light, mystical atmosphere, low key lighting, cinematic 8k photograph, --ar 16:9`
- Пример ARCHIVE: `Soviet scientists in laboratory 1960s, vintage photograph, sepia tones, film grain heavy, declassified document aesthetic, --ar 16:9`

## Камера (camera.movement)
- `dolly_in` — медленный наезд (для напряжения)
- `dolly_out` — отъезд (для откровений, масштаба)
- `parallax_left` / `parallax_right` — горизонтальное смещение (по умолчанию)
- `orbit` — облёт по дуге (для climactic, всё крутится)
- `static` — без движения (только для экстремальных моментов с фокусом на текст)
- `zoom_in_fast` — быстрый зум (для CIPHER, шок)
- `shake_subtle` — лёгкий тремор (тревога)

Для пресета AKA в presets/{name}.json есть `camera_movements` — используй маппинг по mood.

## Переходы (transition_out)
- `default` — стандартный переход пресета
- `between_topics` — между темами одного уровня
- `between_levels` — между уровнями айсберга (фирменный dive transition)
- `shadow_cut` — резкий чёрный с bass-drop (на самых страшных местах)
- `heartbeat_cut` — пульс перед откровением
- `film_burn` — выжигание плёнки (ARCHIVE)
- `glitch` — RGB-сдвиг (CIPHER)
- `warp_zoom` — варп (COSMIC)

## Mood
- `calm` — спокойное повествование
- `tense` — напряжение
- `mystical` — мистика
- `scientific` — научное описание
- `climactic` — пик, откровение
- `mysterious` — загадка

## SFX-маркеры
Если в сцене есть «громкое слово» — добавь sfx с trigger_word:
```json
"sfx": [{"type": "bass_drop", "trigger_word": "исчезли", "intensity": 0.8}]
```
Триггер-слово ищется потом в WhisperX-таймкодах для точной синхронизации.

Типы SFX:
- `bass_drop` — на ключевых страшных фразах
- `whoosh` — при переходах
- `impact` — на ударных словах
- `reverb_tail` — эхо после драматической фразы
- `silence_hold` — 1-2 сек тишины (через музыку duck)

## Текстовые оверлеи (text_overlay)
Используй редко, на ключевых моментах:
- Цифры (статистика): `"60 МИЛЛИОНОВ ДЕТЕЙ"`
- Даты: `"1947 ГОД"`
- Названия: `"ОПЕРАЦИЯ MK-ULTRA"`
- Шок: `"СЕКРЕТНО"`

Стили: `stamp_red` (для ARCHIVE+SHADOW), `glitch_neon` (для CIPHER), `serif_white` (MYSTIC), `mono_white` (COSMIC).

## Анимированные графики (scene.charts)

Используй ОЧЕНЬ ИЗБИРАТЕЛЬНО — только в «доказательные» моменты, где **данные сами по себе являются нарративом**. Чарт без нарративной функции — мёртвый шум, ломающий напряжение.

### Когда ДОБАВИТЬ чарт:
- ✅ Цифра-монстр в voiceover: «погибло сорок миллионов» → `counter` с этой цифрой
- ✅ Шокирующее процентное сравнение: «только 3% знают правду» → `percentage_donut`
- ✅ Рейтинг/сравнение групп: «Корея на 1-м месте по...» → `rank_bar`
- ✅ Один раз перед погружением на новый уровень айсберга — сводка цифр предыдущего уровня

### Когда НЕ ДОБАВЛЯТЬ:
- ❌ В живом эмоциональном рассказе («он оглянулся, и тогда исчез...») — эмоция сильнее данных
- ❌ В climactic-кульминации уровня — финал должен быть про послевкусие, не про статистику
- ❌ Просто потому что в тексте мелькнуло число (контекст важнее)
- ❌ В атмосферной/мистической сцене

### Норма: НЕ больше 1 чарта на 4-5 минут видео. Большинство сцен — БЕЗ чартов.

### Типы и их назначение:
- `counter` — растущая цифра (универсальный, для любой большой цифры)
- `percentage_donut` — кольцо до N% (для контраста «мало vs много»)
- `rank_bar` — горизонтальные бары N стран/групп с подсветкой одной (для сравнений)
- `timeline_bar` — горизонтальная шкала времени с маркерами событий. Подходит для исторических нарративов («путь темы по годам»). 3-5 событий оптимально.
- `iceberg_pyramid` — визуализация уровней айсберга для transition между уровнями. Используй ОДИН РАЗ на видео — обычно перед погружением на новый уровень.
- `map_arrow` — точки локаций + анимированные стрелки от источника. Для геополитики, распространения явлений. Координаты `from`/`to` в процентах [0..100] от размера кадра.

### Schema chart-entry:
```json
"charts": [
  {
    "kind": "counter",
    "trigger_word": "сорок",          // точное слово из этого voiceover; whisper найдёт timestamp
    "duration_sec": 3.5,                // 3-4с — оптимум; не делай меньше 2.5 и больше 5
    "label": "ПОГИБЛО ВСЕГО",            // CAPS, 2-4 слова, описывает контекст числа
    "counter_target": 40000000,         // целевая цифра
    "counter_format": "int_thousands",   // int | int_thousands | float1 | percent
    "counter_suffix": "",                // опц., " ЧЕЛОВЕК" или " $"
    "accent_color": "#ff5050"            // hex; #ff5050 = акцент-красный (default), для «холодных» = #50a0ff
  }
]
```

Для `percentage_donut`:
```json
{"kind": "percentage_donut", "trigger_word": "знают", "duration_sec": 3.5,
 "donut_percent": 3.0, "label": "ЗНАЮТ ПРАВДУ", "accent_color": "#ff5050"}
```

Для `rank_bar`:
```json
{"kind": "rank_bar", "trigger_word": "первое", "duration_sec": 4.5,
 "rank_items": [["США",80],["Россия",65],["Корея",95]],
 "rank_highlight_index": 2, "label": "ПО ЧИСЛУ ШАМАНОВ", "accent_color": "#ff5050"}
```

Для `timeline_bar`:
```json
{"kind": "timeline_bar", "trigger_word": "годами", "duration_sec": 5.0,
 "timeline_events": [["1953","СТАРТ"],["1968","ПИК"],["1991","РАСКРЫТО"]],
 "label": "ХРОНОЛОГИЯ", "accent_color": "#ff5050"}
```

Для `iceberg_pyramid` (на transition между уровнями):
```json
{"kind": "iceberg_pyramid", "trigger_word": "глубже", "duration_sec": 4.5,
 "iceberg_levels": ["ПОВЕРХНОСТЬ","ГОРОДСКИЕ ЛЕГЕНДЫ","СКРЫТЫЕ ФАКТЫ","ЗАПРЕЩЁННОЕ"],
 "iceberg_current_level": 2, "label": "УРОВНИ ЗНАНИЯ", "accent_color": "#ff5050"}
```

Для `map_arrow` (координаты в процентах [0..100]):
```json
{"kind": "map_arrow", "trigger_word": "распространилось", "duration_sec": 5.0,
 "map_origin_label": "КОРЕЯ",
 "map_arrows": [[[45,50],[60,35],"ЯПОНИЯ"], [[45,50],[30,60],"КИТАЙ"]],
 "label": "РАСПРОСТРАНЕНИЕ", "accent_color": "#ff5050"}
```

`trigger_word` ОБЯЗАТЕЛЬНО присутствует в voiceover ЭТОЙ сцены. Иначе чарт не появится.

## Beat-cuts на перечислениях (scene.media_burst)

Когда в voiceover идёт перечисление коротких именований («Азия, Европа, Африка» / «Маркс, Энгельс, Ленин» / «1953, 1968, 1991»), используй media_burst — на каждое слово перечисления на 1 секунду врезается отдельный кадр + camera-click SFX между cuts. Это даёт edit-style ритм типа «о, смотри!» вместо одной статичной картинки.

### Когда добавлять:
- ✅ Перечисление 3-5 имён собственных (страны, люди, события) — каждому свой кадр
- ✅ Список этапов / шагов / категорий
- ✅ Хронологические даты с краткими подписями

### Когда НЕ добавлять:
- ❌ Длинные описательные фразы (там обычная одна картинка работает)
- ❌ Эмоциональный кульминационный момент (бить ритм неуместно)
- ❌ Перечисление >5 элементов (зритель устанет)

### Schema:
```json
"media_burst": {
  "trigger_word": "Азия",
  "items": [
    {"keyword": "asia map dark"},
    {"keyword": "europe medieval map"},
    {"keyword": "africa wildlife sunset"}
  ],
  "item_duration_sec": 1.0,
  "sfx_between": "camera_click"
}
```

- `trigger_word` — первое слово перечисления (по нему whisper найдёт timestamp начала burst'а)
- `items[].keyword` — английский Pexels-search query на каждый элемент. 2-4 слова, конкретно.
- `item_duration_sec` — длина каждого cut'а (0.8-1.2s рекомендуется)
- `sfx_between` — `camera_click` (по умолчанию), `whoosh`, `impact` — короткий звук между кадрами

Items берутся в порядке появления слов в voiceover. Первый item появляется в момент `trigger_word`, остальные — каждые `item_duration_sec` секунд после.

## SHADOW модификатор
Если сцена в 4-м уровне ИЛИ содержит особо тёмное (убийства, исчезновения) — добавь `"modifiers": ["SHADOW"]`. Это включит дополнительные эффекты при сборке.

# КРИТИЧЕСКИ ВАЖНО
- ВЕСЬ текст из сценария должен попасть в voiceover полей сцен (по порядку, без пропусков!)
- Сумма duration_sec должна примерно равняться длительности озвучки (15 минут = 900 сек)
- Каждая сцена ID последовательная: scene_001, scene_002, scene_003...
- НЕ выдумывай сцены — только из сценария
- AI-видео максимум 5-7 на видео (дорого)
- На последнем уровне (4) почти все сцены имеют modifiers: ["SHADOW"]
- В первой сцене после `intro` должен быть `intro_sting.mogrt` маркер
- Между уровнями обязательно `level_card_X.mogrt` через level_transitions
- `level_titles` — короткий жирный заголовок для КАЖДОГО уровня (1..N) под тематику этого видео.
  Каждое значение CAPS, 1-3 слова. Это покажется на cinematic-плашке «УРОВЕНЬ N / <TITLE>»
  при каждой смене уровня. Примеры жанров:
  айсберг историй → "ОФИЦИАЛЬНАЯ ИСТОРИЯ" / "ГОРОДСКИЕ ЛЕГЕНДЫ" / "СКРЫТЫЕ ФАКТЫ" / "ЗАПРЕЩЁННОЕ";
  айсберг существ → "ИЗВЕСТНЫЕ" / "СОМНИТЕЛЬНЫЕ" / "ОПАСНЫЕ" / "АНОМАЛЬНЫЕ".
