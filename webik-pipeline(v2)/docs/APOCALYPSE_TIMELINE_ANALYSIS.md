## Голос — ключевое открытие

**VO Айдара — это ОДИН mp3-файл** `E:\YouTube Webik\14 видос, Апокалипсис\Апокалипсис.mp3` (а не отдельные чанки).

На таймлайне он нарезан на **39 сегментов** на A1. Каждый сегмент — это subclip того же mp3 со своим In/Out point'ом.

**Что это означает для pipeline:**
- Voicer (Webik V3 шаблон) дёргается **ОДИН раз** на весь длинный текст → выдаёт один длинный mp3 → ровная интонация по всему видео
- Pipeline затем нарезает этот один mp3 на сегменты по сценам (через faster-whisper alignment)
- На таймлайне каждая сцена = subclip одного mp3 с разным in_point/out_point
- НЕ генерить голос по сценам отдельно — иначе интонация будет скакать (что и происходило в прошлых билдах)

## Переходы — все 96 классифицированы

**Все 96 переходов = Dip to Black** (`AE.ADBE Dip To Black`). Ни одного другого типа. Это сильно упрощает дизайн pipeline.

### Длительности по трекам

| Трек | Кол-во | Длительность |
|---|---|---|
| **V1** | 36 | 34× по **1.0 сек** (30 кадров) + 2× по 0.833 сек |
| **V2** | 29 | 29× по **0.833 сек** (25 кадров) |
| **V3** | 20 | 20× по **0.833 сек** |
| **V4** | 11 | 10× по **0.833 сек** + 1× по 0.7 сек |

**Стандарт Айдара:**
- MOGRT-слой V1: **Dip to Black 1.0 сек** на каждом стыке
- Overlay-слои V2-V4: **Dip to Black 0.833 сек** (25 кадров)

### Incoming/Outgoing pattern

- **51** outgoing=true, incoming=false → fade-out на конце клипа
- **41** outgoing=false, incoming=true → fade-in в начале клипа
- **4** обе стороны → классический центрированный A→B переход

То есть **большинство переходов — solo fade-in/out**, а не классический A→B. Это логично для overlay-слоёв: оверлей появляется на чёрном (fade in), потом исчезает (fade out). Между ними может быть прозрачный gap.

### Alignment values

- 0: 45 (в начале клипа — fade in)
- 211680000000 ticks (0.833s): 33 (центр стыка для 0.833s переходов)
- 254016000000 ticks (1.0s): 17 (центр стыка для 1.0s переходов)
- 177811200000 ticks (0.7s): 1 (один особый случай на V4)

### Что это значит для pipeline

При сборке нового видео pipeline должен:
1. На стыках V1 (MOGRT-плашек) — ставить `AE.ADBE Dip To Black` длительностью **1.0 сек**
2. На fade-in/fade-out клипов V2-V4 — ставить `AE.ADBE Dip To Black` длительностью **0.833 сек**
3. Параметры по умолчанию: `StartPercent=0, EndPercent=1, BorderWidth=0, BorderColor=0,0,0, Reverse=false, Direction=0`
4. Большинство alignment=0 (fade-in соло-клипа) или alignment=duration (центрированный)

## Архитектура для v2 pipeline

```
V1: MOGRT-плашки (level cards + Film Title) + редкие inserts
    ↑
V2: основной видеослой (стоки + фильмы + мемы)
V3: второй видеослой (доп.иллюстрации, ТВ-новости)
V4: тематический слой (религия/мифология/катастрофы)
V5: Adjustment Layer (грейдинг) + маскот бебрик
V6: одиночные элементы
V7-V8: НЕ ИСПОЛЬЗУЮТСЯ

A1: ОДИН VO mp3, нарезан на сегменты ← главный sync
A2: SFX (клавиатура, вуш, затвор, глитчи)
A3: эмоциональная музыка (Эпично, Dark Ambient, хор)
A4: подложка ambient-back
A5-A10: НЕ ИСПОЛЬЗУЮТСЯ
```

**Что v2 pipeline должен делать:**
1. Брать готовый `.prproj` (например `13 Апокалипсис.prproj`) как skeleton
2. Парсить SubClip + MasterClip XML
3. Заменять MasterClip.FilePath на новые источники (Pexels/Pixabay/Local CLIP) под новую тему
4. ОДИН раз дёргать Voicer на полный текст → подставлять как новый `Апокалипсис.mp3` (или аналог)
5. Whisper-aligner режет mp3 на segments → подставляет start/end в A1.SubClip-ах
6. Не трогать V1 MOGRT-плашки (level cards, Film Title) — реюзать
7. Не трогать A2-A4 музыку/SFX — реюзать
8. Adjustment Layer на V5 = глобальный градинг, тоже реюзать
